# /comet

Comet (Perplexity) Deep Research writes its output here, **directly to the GitHub repo** `github.com/blake-a11y/EDCs` under this `/comet/` path. Comet cannot access the desktop, so it commits to GitHub.

- `comet_results.csv` — the 39-column result file (see `/01_contract/DATA_CONTRACT.md`). Complete file re-committed at the end of every research phase.
- `comet_evidence_log.md` — the "show your math" proof, appended each phase.

Comet must match the data contract exactly. Do not put Claude output in this folder.
