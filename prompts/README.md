# /prompts

The phased prompt documents go here once written.

- `claude_prompts.md` — the full phased prompt set for Claude Opus 4.8 Deep Research.
- `comet_prompts.md` — the full phased prompt set for Comet Deep Research.

Each doc contains Phase 0 through Phase 5. You paste one phase at a time into the bot; each phase ends by gating on "Go" before the next runs.
