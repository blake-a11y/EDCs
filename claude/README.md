# /claude

Claude Opus 4.8 Deep Research output lands here, on the **desktop** copy. Claude cannot save files itself: it prints results in its chat, you paste them into the reconciliation Claude chat, and Claude writes them here.

- `claude_results.csv` — the 39-column result file (see `/01_contract/DATA_CONTRACT.md`). Complete file re-written at the end of every research phase.
- `claude_evidence_log.md` — the "show your math" proof, appended each phase.

Do not put Comet output in this folder.
